# Tylix (.tyx) — Language, Themes & Icons

- Syntax highlighting for `.tyx` pages, components and capabilities (`{{ }}` expressions, `{{#if}}` / `{{#each}}`, embedded TypeScript and HTML, Tailwind class colouring)
- **Tylix Dark** and **Tylix Light** colour themes
- **Tylix Icons** file icon theme

After installing: `Ctrl+K Ctrl+T` for the colour theme, and `Preferences: File Icon Theme` for the icons.
